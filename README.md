Cleanup چرا لازم است؟

در این تمرین با استفاده از setInterval یک تایمر ایجاد کردیم که هر یک ثانیه مقدار را تغییر می‌دهد.

چون این تایمر خارج از روند معمول رندر شدن کامپوننت اجرا می‌شود، هنگام حذف شدن کامپوننت باید آن را متوقف کنیم.

برای این کار از تابع Cleanup استفاده می‌کنیم:

return () => {
  clearInterval(id)
}

وقتی کامپوننت از صفحه حذف شود، Cleanup اجرا می‌شود و clearInterval تایمری را که قبلاً ساخته‌ایم متوقف می‌کند.

اگر Cleanup نداشته باشیم، تایمر می‌تواند بعد از حذف کامپوننت هم به اجرای خودش ادامه دهد و باعث مصرف منابع و رفتارهای ناخواسته شود.

خلاصه:

setInterval → ایجاد تایمر
clearInterval → متوقف کردن تایمر
return داخل useEffect → تعریف Cleanup
